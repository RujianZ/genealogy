# 张氏宗谱 · 胜二户

湖北黄梅《张氏宗谱》胜二户，2016 年第十届续修，全四册 1,314 页。
上溯到南宋宝庆丁亥（1227）迁梅始祖张胜二，到今天二十七世，跨 772 年。

把这部谱做成一个**能查、能追到原文**的网页。

```bash
node --experimental-strip-types tools/check.mjs     # 四组检查，全过才能发
node --experimental-strip-types tools/bundle.mjs    # 打成单个 HTML
```

产出 `build/张氏宗谱.html`——一个文件，双击就能看，不用装东西、不用联网。

---

## 三条规矩

这三条不是风格偏好，是这个项目存在的理由。出自这部谱自己的凡例和历届序：

> **不缘情而增，不故意而减**　　乾隆四十一年（1776）古岩国茂
> **纪其所可知，阙其所未知**　　道光五年（1825）默齐拔萃

**不猜**　谱上写「某某之子」而同名的有几个，绝不替谱做决定。候选全列出来，标明谱没说是哪一个。

**不漏**　搜索结果一条不截。低分的排在后面，但一定列出来。

**可追溯**　每一页底部固定显示**册几·卷几·第几页·第几行**，点开就是谱上那一段的原文，一个字没改。

## 目录

```
source/     2016 年那一届的 Word 原件和封面照片。**这是唯一的原始材料。**
              合一/合二/合三 是三册世系正文，正文是打字打进去的；
              张氏谱首（一）.doc 248 页是扫描图片
data/       解析产物。people.json 是第一段的成果，**任何时候都不改它**
src/core/   判据与显示逻辑（TypeScript，Node 自带类型擦除，零依赖）
prototype/  界面（index.html + app.js）
tools/      校验、审计、打包、查原件
work/       中间产物，可重新生成
build/      成品 HTML，可重新生成
```

## 四组检查

```
verify_all   数据不变量：原文一字不动、指向都存在、三条原则、世系走得通
smoke        界面走不走得通：搜索、点开、树、关系计算、译文、疑点
noloss       有没有把真的关系删掉（子女栏重写后的反向查）
nohardcode   判据里有没有针对某个具体的人写死——**有就不算函数了**
```

## 查原件

```bash
python tools/rawctx.py "source/合一（1.2.3.4）.doc" 继发 22
```

把 2016 年那份 Word 里任何一处的逐段原文调出来。数据里看不出的东西，翻原件往往一眼就看见——
「粱四」那个排版误字、「继发／和／才」共用辈字的写法，都是这么查出来的。

## 不做的事

年号／农历转公历、向量检索、后端服务器、登录账号、任何形式的商业化与埋点。
不改写、不清洗、不「修正」任何原文字段——谱上写「光绪二十六年月日时缺」，
那个「缺」是当年编谱人写下的「这里没有记录」，原样显示。
