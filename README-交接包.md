# 交接包说明

```
CLAUDE.md              ← 放项目根目录，Claude Code 每次都会读
data/
  people.json          ← 主数据。2,258 人，4.3MB，gzip 后 466KB
  genealogy.db         ← SQLite，同样内容 + 边表 + 别名表，方便你自己查
  02b_查无父名条目.csv   ← 263 条，父名在谱中查无此条目
  02c_多条父边的人.csv   ← 854 人，含全部候选（界面上要显示成分叉的就是这些）
  04_未归属文本.csv      ← 3,221 行解析器认不出的原文，一行没丢
parser/
  *.py                 ← 第一段解析器源码，能重跑
  jsonl/               ← 四册无损提取的原始 JSONL
  README-解析器.md
assets/
  cover.webp           ← 卷首红底封面，做加载页用
  shantu/*.webp        ← 16 幅手绘山图
```

## 山图对照

原书卷首有 16 幅手绘风水图，每幅配一段题记（题记文字在 `parser/jsonl/张氏谱首_一_.jsonl` 里）。

| 文件 | 是什么 |
|---|---|
| `shantu-01.webp` | **蔡山镇陈埠港，鲤鱼形——始祖胜二公墓**（图上写着"陈埠庵""社庙""来龙""来水""去水"） |
| `shantu-02.webp` | 多云山，金绒吊葫芦形——**合族祖山**（题记老实话：「虽非富贵美地」） |
| `shantu-03.webp` | 什村镇细山咀，金盘托果形——十世七相公 |
| `shantu-04.webp` | 本屋墩大坟林，蜘蛛形——有禄公与硺公 |
| `shantu-05.webp` | 茶儿镇毛狗冲，众星拱月——十五世梦骥公 |
| `shantu-06.webp` | 苦竹口牌子山，仙人打纲形——朝寿公 |
| `shantu-07.webp` | 多云镇上伎羊村高坟坦 |
| `shantu-08.webp` | **蕲州何家铺蔡山窊，金盘架形——十七世焕先公墓** |
| `shantu-09` ~ `16` | 梅家湾、傅家垏、姚家垅、团鱼地、夏家场、茅家菴、沙岭岗、安德山 |

**01 和 08 是最有分量的两幅**：一幅是全族起点，一幅是那位 1710 年
首修族谱、修完三年就去世的十七世祖。做界面时可以用。

## 三件事需要你自己补

1. **手机端的"我是谁"选择器**需要一份房支列表——从 `people.json` 的
   `src.section` 字段直接聚合即可（学义公世系、学仁公世系、朝寿公世系…）
2. **字体**：思源宋体 / Noto Serif SC，自己下
3. **图标**：可以从 `cover.webp` 里那个黑底黄边的族徽抠

## 数据还会更新

解析器还在改（未归属文本聚类、缺失声明单独成字段、卷首文献全文检索）。
`people.json` 会有新版本，**但字段结构不会破坏性变更**——只会加字段，不会删或改语义。

按 `CLAUDE.md` 第三节的契约写代码就行。
