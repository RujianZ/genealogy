# 完整性审计 · 从原始 .doc 出发

**结论：三条独立路径逐字对完账，并集 208,730 字，没有任何一路是完整的。**

## 一、原件台账

四份 `.doc` 文件头均为 `D0 CF 11 E0 A1 B1 1A E1`，确认是真 OLE2 复合文档（Word 97），
不是改了后缀的 docx。

| 文件 | 字节 | SHA256(前16) |
|---|---:|---|
| 张氏谱首（一）.doc | 24,374,272 | 255607FD4A1F6E01 |
| 合一（1.2.3.4）.doc | 5,011,456 | B849E2841D9DEA2B |
| 合二（5、6、7）.doc | 5,532,672 | AE9716E48AF89B32 |
| 合三（8、9）.doc | 3,751,936 | 49DF72DA773F43E0 |

另有 4 张封面 JPEG、4 张印刷拼版 JPEG，均确认 `FF D8 FF` 头。

## 二、方法

**两个互不相干的引擎**各自把 `.doc` 转成 `.docx`：

- **Microsoft Word 16.0**（COM 自动化）—— 微软自己的参考实现
- **LibreOffice 25.x**（`soffice --headless --convert-to docx`）—— 独立第三方实现

然后用同一个穷举提取器 `tools/harvest.py` 处理两边产出：

- **不挑部件**：docx 内所有 `.xml`/`.rels` 部件全遍历（页眉、页脚、脚注、尾注、
  批注、文本框、组合图形都在内），不是只读 `word/document.xml`
- **不挑标签**：`w:t` / `w:delText`（修订删除的）/ `w:instrText`（域代码）/
  `a:t`（DrawingML 图形文字）/ `v:textpath`（VML）/ `m:t`（公式）全收
- **未知带字标签会报出来**，不静默跳过
- `mc:AlternateContent` 只计 `Choice`，`Fallback` 单独记账不计入总数

最后用 `tools/compare.py` 按**字符多重集**逐字比对——总数相等不算数，
必须精确到「哪个字、多几个、少几个」。

## 三、结果

| 路径 | 去空白字数 | 相对并集缺什么 |
|---|---:|---|
| 交接包现有 JSONL | 208,670 | 页脚页码域 **36 字** |
| Microsoft Word 16.0 | 208,630 | 世代列头 **100 字** |
| LibreOffice | 208,706 | 第二个页脚的 PAGE 域 **24 字** |
| **三路并集** | **208,730** | **—** |

### 3.1 Word 丢的 100 字：世代列头

```
合一 75 字   第一世 第六世 十一世 十六世 廿一世 …
合三 15 字   廿六世 … 三十世
其余 10 字   同类
```

这些字在**组合图形（drawing canvas）**里。微软自己的 Word 转 docx 时把它们扔了，
LibreOffice 保住了。grep 复验：Word 产出的 `合一/合二/合三` 里一个「第X世」都没有。

**这 100 字不是可有可无的**——CLAUDE.md 第四节写明「世次由原书自己的
『第一世…第五世』世代列头标死，不是推算出来的」。它们是全谱世次体系的锚点。

### 3.2 JSONL 丢的 36 字：页脚页码

每册 9 字，结构一致，位于 `word/footer1.xml`：

```
[正文] '·'   [域代码] ' PAGE '   [正文] '447'   [正文] '·'
```

即页脚的 `·447·`。四册共 36 字。

### 3.3 LibreOffice 丢的 24 字

Word 产出含 `footer1.xml` + `footer2.xml`（单双页各一），LibreOffice 只产出
`footer1.xml`，因此少一组 `PAGE` 域，每册 6 字，四册 24 字。

### 3.4 关键关系

```
LibreOffice 提取  ⊇  现有 JSONL     （逐字验证：JSONL 有而 LO 无 = 0 字）
完整集 = LibreOffice ∪ Word = 208,730 字
```

现有 `people.json` 这条链上**除页脚外没有丢过字**。交接包是可信的。

## 四、过程中修掉的一个自身 bug

第一版 `harvest.py` 用 `id(el)` 建集合来跳过 `mc:Fallback`。
**lxml 的元素是临时代理对象，两次遍历同一底层节点会拿到不同的 `id()`**，
集合根本命中不了。后果：LibreOffice 把每个文本框同时写成
`Choice(DrawingML)` + `Fallback(VML)` 两份，卷首 47,837 字被数成 91,971 字。

改为沿祖先链 `iterancestors()` 实时判断后消失。

教训记一条：**数字异常先怀疑自己的计数器，再怀疑数据。**
当时差 44,143 字，我一度以为是找到了 JSONL 漏掉的《甲子录》——
实际三方都有《甲子录》，是我数了两遍。
