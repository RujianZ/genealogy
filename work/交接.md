**贯穿全程的三条原则（用户自己定的）：**
- **不猜** — 一人有几个说法的父亲就并存，各注依据强弱，绝不取一弃余
- **不漏** — 名字有几种写法就全列，繁简异体都要试
- **可徵** — 每一句话系上册·卷·页·行，附原文

**判断次第：** 谱的原话 > 谱的定式（世次、行列） > 年月算术 > 推断。凡是拿弱规则压谱上明文的，都算我们错。

## 三、工具（我写的，都在 `D:/族谱/tools/`）

环境里 poppler 已通过 scoop 装好（`pdftoppm` `pdfinfo` `pdftotext`）。
**ImageMagick 装了但是坏的**（找不到 PNG 解码模块，`montage` 用不了），所以我自己写了 PPM 解析 + PNG 编码。

```bash
export PATH="$HOME/scoop/shims:$PATH"     # 每次 Bash 调用都要加

# 版心条拼图：裁每页书口那一条，横排。用来快速摸卷次分布
node tools/sheet.mjs <pdf> <起页> <止页> <步长> <输出png>

# 整页网格拼图：连续若干页缩排成一张。用来「扫」而不是「读」
node tools/grid.mjs <pdf> <起> <止> <每行几页> <dpi> <输出png>

# 挑页拼图：给一串不连续页码。用来定位卷次边界
node tools/pick.mjs <pdf> "1,50,100,200" <每行几页> <dpi> <输出png>
```

**放大某一处用 pdftoppm 的裁剪参数：**
```bash
pdftoppm -r 300 -f <页> -l <页> -png -x <左> -y <上> -W <宽> -H <高> <pdf> <前缀>
```
坐标是**该 dpi 下的像素**。先算全页尺寸：`页宽pt / 72 * dpi`。

**经验值：**
- 甲道谱页面 528×975 pt（单半叶），150dpi 看版心，300dpi 读正文
- 光绪县志页面 2724×2312 pt（双页跨页，很大），60–70dpi 扫名单，120–130dpi 读，300dpi 特写
- 乾隆县志页面 514×731 pt，130dpi 扫，210–320dpi 读
- 网格拼图一次 6 页最好读；超过 12 页就只能认版心不能认人名

## 四、已完成 A：甲道谱比对（**已出结论**）

### 背景

本谱卷首《源流序》（北宋元祐八年 1093，写于乐平）有一句话：

> 「徹生敬，敬生知進，知進又徙居鄱陽之樂平南偏蒿子埠……即今新營是也。」

**九百三十三年来无人能核。** 1739 年十八世祖学光（字素登）渡江去乐平请谱，但只核了下半程（十院→胜二），且只抄回结论没抄原文。

**要找张胜二本人，六种写法都要试：** `勝二 · 胜二 · 大勳 · 大勋 · 騰二 · 腾二`
（「腾二」来自本谱第二世文端条的刻误：「腾二公幼子」，实为胜二）

**结构性结论（已验证）：县志收人靠「事」不靠「名」。** 選舉志收有功名的，秩官志收来做官的，墳墓志收有头衔或孝节事迹的，孝友传收有孝行的。胜二在谱上唯一的事迹是「由选举恩授遵化卫官」，而选举志不认这条——没有事就没有条目。**这不构成「他不存在」的证据**：明洪武十四年以他名字立的民户、那座壬丙向有碑的坟、被人叫成「张胜二」的村，都不需要县志背书。

## 八、几个反复踩过的坑

1. **中文经 bash 传参会被搞坏。** 构造 URL、写含中文的脚本，一律用 Node 的 `encodeURIComponent` 或 `Write` 工具，别用 heredoc 混中文。
2. **文件名带繁体字（黃、岡）在 SendUserFile 里会乱码**，命名用 ASCII。
3. **Commons API 会限流**，要带 User-Agent 并且请求间隔 ≥1.5 秒；大文件下载用 curl 断点续传，不要用 fetch 一次性拉。
4. **缩略图上认错字是常事。** 我犯过三次：把「項榮善」看成「張先羨」，把楊穴鎮的張家村算进什村镇，把「離城十里」看成「十五里」。**任何要写进结论的字，必须 300dpi 特写复核一遍。**
5. **抽样不等于查证。** 我曾抽查 6 页版心就断言「缺卷二到卷二十」，被用户质疑后才逐页坐实。名单类的东西要么全扫，要么明说是抽样。
6. **网格拼图超过 12 页就只能认版心，认不了人名。** 要读名字，一次最多 6 页。
